# Release Notes

## Version 1.0.0 (Current)

Initial release of the Chess Board Drawer application.

### Features

- Interactive chess board with customizable size (4×4 to 16×16)
- Six color themes: Classic, Vintage, Purple, Gray, Blue, and Red
- Board size adjustment controls
- Animation toggle
- Integration with chess game component
- Clean, intuitive user interface
- Standard chess notation labels for 8×8 boards

### Requirements

- Python 3.6 or higher
- Turtle graphics module (included in standard Python)
- Tkinter (for chess game component)
